Finlande : délai de recours contre un refus d'asile

Les délais ci-dessous concernent le recours contre un refus d'asile en Finlande. Le délai exact figure au bas de votre décision ; fiez-vous toujours à lui.

Type de décisionDélai de recours
Rejet ordinaire30 jours
Procédure accélérée10 jours
Procédure à la frontière10 jours
Décision d'irrecevabilité10 jours
Dublin / transfert vers un autre pays14 jours
Mesure provisoire urgente7 jours

Nous n'avons pas pu vérifier entièrement les règles de ce pays ; nous indiquons donc le jour le plus tôt possible. Suivez le délai indiqué dans votre décision.

Où et comment faire recours

Instance de recours
Hallinto-oikeus
Point de départ du délai
Le jour où la décision vous est notifiée. Par prudence, comptez à partir de la plus ancienne de deux dates : celle inscrite sur la décision ou le jour où vous l'avez reçue.
Si le dernier jour tombe un week-end
Aucune prorogation n'est confirmée : déposez le recours le jour ouvrable précédent.
Juridiction supérieure
Korkein hallinto-oikeus
Avocat devant la juridiction supérieure
Non obligatoire

Qui peut déposer le recours ?

Dans ce pays, vous pouvez en général déposer le recours vous-même, sans avocat.

Il s'agit d'une estimation qui indique volontairement le jour le PLUS TÔT possible. Votre délai exact figure dans votre décision ; suivez toujours le délai de votre décision. Certains pays ajoutent des jours pour une décision envoyée par la poste ; n'y comptez pas.

Nous rédigeons votre requête en recours. Écrivez-nous avant la fin du délai.
