Luxembourg : délai de recours contre un refus d'asile

Les délais ci-dessous concernent le recours contre un refus d'asile en Luxembourg. Le délai exact figure au bas de votre décision ; fiez-vous toujours à lui.

Type de décisionDélai de recours
Rejet ordinaire20 jours
Procédure accélérée10 jours
Décision d'irrecevabilité10 jours
Dublin / transfert vers un autre pays10 jours

Les règles de ce pays ont été confirmées avec une faible certitude ; le résultat indique le jour le plus tôt possible.

Qui peut déposer le recours ?

Dans ce pays, le recours est en règle générale déposé par un avocat ; vous ne pouvez pas le faire seul. Demandez tout de suite un avocat gratuit (aide juridictionnelle). Nous pouvons préparer le texte du recours pour votre avocat.

Il s'agit d'une estimation qui indique volontairement le jour le PLUS TÔT possible. Votre délai exact figure dans votre décision ; suivez toujours le délai de votre décision. Certains pays ajoutent des jours pour une décision envoyée par la poste ; n'y comptez pas.

Nous rédigeons votre requête en recours. Écrivez-nous avant la fin du délai.
